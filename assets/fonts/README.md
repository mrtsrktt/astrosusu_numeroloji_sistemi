# Bundled report fonts

- Carlito Regular and Bold: https://github.com/google/fonts/tree/main/ofl/carlito
  License: `Carlito-OFL.txt` (SIL Open Font License 1.1).
- Lora variable upright (default weight used for titles): https://github.com/google/fonts/tree/main/ofl/lora
  License: `Lora-OFL.txt` (SIL Open Font License 1.1).

These unmodified font files support Turkish characters and may be bundled and
embedded under their accompanying licenses. PDF generation loads them relative
to the application directory, without operating-system font dependencies.
